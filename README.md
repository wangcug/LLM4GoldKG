# LLM4GoldKG

The statements in the Extract_Prompt file are used to guide the large language model to extract the geological entities and their semantic relationships in different articles;

The code in Translate_to_cypher is used to convert the geological entities and their semantic relationships stored in the Excel table into Cypher statements;

Translate1 and Translate2 are respectively used to translate the Cypher statements in Chinese into English, corresponding to the translation of individual geological entities and the translation of geological entities and their semantic relationships respectively, and to remove duplicates for repeated entities.
